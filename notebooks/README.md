# Notebooks Directory

This folder holds experimental Jupyter notebooks for iterative development:

- `01_data_exploration.ipynb`: Visualizing sample fruit images and color distributions across classes.
- `02_color_segmentation_experiments.ipynb`: Tuning HSV thresholds, K-means clustering parameters, and morphological filters.
- `03_feature_analysis.ipynb`: Evaluating color moment distributions and statistical separability between ripeness stages.
- `04_model_prototyping.ipynb`: Rapid experimentation with SVM, Random Forest, and CNN architectures.
